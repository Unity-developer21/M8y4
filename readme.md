# системный телеграм бот 🤖

простой и полезный бот, который помогает следить за вашим компьютером прямо из telegram

## 🌟 что умеет бот

- **показывает состояние пк**: загрузка процессора, оперативная память, свободное место на диске и сетевой трафик
- **делает скриншот**: со своего компьютера с выбором задержки (0, 3 или 5 секунд)
- **записывает звук**: с микрофона и отправляет вам голосовое сообщение (5, 10 или 20 секунд)
- **безопасность**: бот отвечает только вам по вашему `ID` и игнорирует чужие команды

---

## 🛠 что нужно установить перед запуском

для работы бота понадобятся несколько библиотек в python

открой терминал или командную строку и введи:

```bash
pip install pyTelegramBotAPI psutil pyautogui sounddevice scipy
```

---

## 🚀 как настроить и запустить

1. скачай файлы проекта в одну папку
2. создай файл `config.py` в той же папке и напиши туда:

```python
TOKEN = "твой_токен_от_botfather"
ID = 123456789  # твой telegram id
```

> **как узнать свой telegram id?**  
> напиши боту `@userinfobot` в telegram, он пришлет твой ID

3. запусти файл `bot.py`:

```bash
python bot.py
```

---

## 📱 как пользоваться

1. зайди в telegram и найди своего бота
2. напиши команду `/start`
3. напиши `/status` чтобы получить полный отчет о системе
4. нажимай на кнопки под отчетом, чтобы сделать скриншот или записать звук
